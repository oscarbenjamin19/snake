# Snake

A terminal Snake game for Windows, written in Python.

## Requirements

- Python 3.x
- Windows (uses `msvcrt` for keyboard input)

## How to run

```bash
python snake.py
```

## Controls

| Key | Action |
|-----|--------|
| Arrow keys | Move the snake |
| Q | Quit |

## Rules

- Eat the food (`@`) to grow and earn 10 points
- The snake speeds up as your score increases
- Hitting a wall or yourself ends the game
